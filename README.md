## ✨ Features

* Responsive photography website
* Hero section introducing the photography business
* Photographer profile and About section
* Photography services and packages
* Individual galleries for different types of shoots
* Client testimonials
* Booking/enquiry section
* Contact information and enquiry form
* Social and external links
* Video content
* Responsive navigation and layout

## 📸 Photography Services

The website showcases a range of photography services, including:

* Weddings
* Matric dances
* Pregnancy shoots
* Birthday shoots
* Graduation shoots
* Outdoor events
* Family portraits
* Corporate and other special events

Each service can include a dedicated gallery and photography package information.

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

Clone the repository:

```bash
git clone https://github.com/YolandaMbande/nestashots.git
```

Navigate into the project:

```bash
cd nestashots
```

Install the dependencies:

```bash
npm install
```

### Run the project locally

Start the Webpack development server:

```bash
npm start
```

The project is configured to use Webpack's development server for local development.

### Build for production

```bash
npm run build
```
